# 동고오래~ㅂ — 제7회 부산동고 오픈랩 모션 필름 (44초)

1920×1080 · 60fps · H.264 + AAC. 이미지 파일 없이 코드로만 그린 광고 영상입니다.
(학교 엠블럼만 브로슈어에서 알파 마스크로 추출해 사용)

## 구성 (120 BPM, 2초 = 1마디)
| 시간 | 장면 |
|---|---|
| 0–2 | 엠블럼 빌드 |
| 2–6 | 학교 소개 벤토 (과학중점학교 · 영재학급 · 무한상상실) |
| 6–8 | "오늘의 탐구가" |
| 8–24 | 부스 8종 × 2초 — 대표 부스, 층·실 위치, 부스 목록, 활동 일러스트 |
| 24–26 | 12개 동아리 · 32가지 체험 요약 |
| 26–28 | "내일의 가능성이 되는 곳" |
| 28–32 | 2026 주요 대학 대입 결과 |
| 32–34 | 스탬프 랠리 |
| 34–36 | 제7회 빌드업 |
| 36–40 | 동고오래~ㅂ 타이틀 · 날짜 · 오시는 길 |
| 40–44 | 엔딩 · 크레딧 (이동혁) |

## 파이프라인
- **화면** `film.js` — Node.js + `@napi-rs/canvas`(Skia). 모든 장면은 시간 t → 화면 함수. 이징·스프링·카메라·흔들림 직접 구현. 폰트는 Pretendard + JetBrains Mono.
- **모션블러·후처리** `render.js` — 180° 셔터 서브프레임 누적(평소 4장, 빠른 구간 12장), 블룸·색수차·글리치·비네팅·임팩트 플래시.
- **소리** `music.py` — numpy/scipy로 파형부터 합성(오실레이터, 필터, 엔벨로프, 컨볼루션 리버브, 사이드체인, 컴프레서). 타임라인은 영상과 공유.
- **인코딩** ffmpeg — 프레임을 stdin으로 바로 넘겨 4:4:4 중간본 → 필름 그레인 + AAC를 입힌 H.264 최종본.

## 실행
```bash
npm install
pip install numpy scipy imageio-ffmpeg
python3 music.py                 # build/audio.wav, build/audio_features.json
node render.js sheet             # work/sheet.png 컨택트 시트
node render.js full 4            # out/donggo-openlab-2026.mp4 (워커 4개)
```
